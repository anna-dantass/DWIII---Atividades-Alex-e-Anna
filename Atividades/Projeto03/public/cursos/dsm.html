📱 Desenvolvimento de Software Multiplataforma

⏱ 6 semestres 🌤 Tarde 🏫 Presencial 🎓 Tecnólogo

O curso prepara o aluno para criar aplicações que funcionam em diferentes plataformas: web, dispositivos móveis, nuvem e Internet das Coisas. O ensino é baseado em projetos (ABP): a cada semestre os alunos desenvolvem um projeto integrador em equipe, aplicando o que aprenderam nas disciplinas.

O que você vai estudar

Desenvolvimento

Desenvolvimento Web (I, II e III), programação para dispositivos móveis e APIs.

Dados

Banco de dados relacional e não relacional, estatística e ciência de dados.

Tecnologias atuais

Computação em nuvem, Internet das Coisas, inteligência artificial e segurança.

Onde pode trabalhar

  • Desenvolvedor web e mobile
  • Desenvolvedor de soluções em nuvem e IoT
  • Analista de testes / QA
  • Analista de dados
