# DWIII - Atividades

Este repositório será usado para as atividades que o professor passar na
disciplina de **Desenvolvimento Web III**, do curso de Desenvolvimento de
Software Multiplataforma da FATEC Zona Sul. A cada nova atividade, uma pasta
será adicionada dentro de [`Atividades`](Atividades).

> **Sobre as atividades:** tudo o que está sendo feito aqui tenta usar
> **somente o que foi ensinado em aula**. A exceção são as pastas
> `*_Estilizado`: elas têm o mesmo servidor, as mesmas rotas e o mesmo
> conteúdo da versão principal, mas usam um **CSS com bem mais conhecimentos**
> do que o visto em aula.
